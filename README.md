# Repo de obligatorio Ansible Taller Agosto 2026

En este repo se implementa mediante Ansible el automatismo para configuración y despliegue de:
### Servidor CentOS Stream
- Instalación de Apache y PHP.
- Instalación de las extensiones necesarias para conectarse a MariaDB.
- Despliegue de la aplicación PHP.
- Configuración y administración de Apache mediante systemd.
- Configuración de firewalld para permitir el acceso HTTP.
- Configuración de los archivos de la aplicación mediante variables o templates.
### Servidor Ubuntu Server
- Instalación de MariaDB Server.
- Configuración y administración de MariaDB mediante systemd.
- Creación de la base de datos, tablas y datos iniciales.
- Creación de un usuario específico para la aplicación.
- Configuración de MariaDB para aceptar conexiones desde el servidor CentOS.
- Configuración de UFW para permitir el acceso a MariaDB únicamente desde el
servidor de aplicación.
